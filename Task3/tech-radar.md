# Технический радар (Tech Radar)

| **Категория / Статус**            | **Adopt**                                                                                                                                                 | **Trial**                                                                                                                                        | **Assess**                                                                                                                                                                | **Hold**                                                                                                                                                     |
|-----------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Методологии**                   | - **Domain-Driven Design (DDD)**<br/>- **Event-Driven Architecture**<br/>- **DevOps & CI/CD**                                                            | - **Data Mesh** (расширение DDD-принципов для данных)<br/>- **Micro Frontends** (для крупных портальных UI)                                        | - **DataOps** (рассматриваем комплексные практики для управления данными в ML/аналитике)                                                                                    | - **Waterfall-процессы** (уходим от классической каскадной модели)                                                                                           |
| **Интеграция / Коммуникации**     | - **Kafka/RabbitMQ** (EventBus)                                                                                                                           | - **gRPC** (дополнение к REST)<br/>- **Apache Pulsar**                                                                                             | - **GraphQL** (в отдельных сервисах для облегчения агрегации данных)                                                                                                       | - **Apache Camel** (устаревшая шина, постепенно выводим из эксплуатации)                                                                                    |
| **Хранилища и базы данных**       | - **Data Lake** (HDFS / объектное хранилище)<br/>- **Колонночная/MPP-БД** (Snowflake, Greenplum, ClickHouse)                                              | - **NoSQL (MongoDB, Cassandra)** для специфических кейсов                                                                                         | - **Time-Series DB** (InfluxDB / TimescaleDB) — рассматриваем для IoT/метрик                                                                                              | - **Microsoft SQL Server 2008** (устаревший DWH; остаётся для исторических данных, планируется постепенный вывод)                                            |
| **Обработка данных (ETL/ELT)**    | - **Airflow / NiFi** (оркестрация потоков данных)<br/>- **dbt** (декларативные трансформации)                                                             | - **Spark Structured Streaming** (проверяем стрим-аналитику в режиме реального времени)                                                           | - **Flink** (для поточной аналитики, если потребуются сложные сценарии)                                                                                                     | - **PowerBuilder SQL-процедуры** (наследие внутри DWH, уходим от этого подхода)                                                                              |
| **Каталог и управление данными**  | - **Data Catalog / Governance** (Collibra, DataHub, Hive Metastore)                                                                                      | - **Automated Data Lineage** (автоматический трекинг связей между таблицами, см. OpenLineage, Marquez)                                             | - **MLflow** (или похожие инструменты для управления ML-моделями)                                                                                                          | - **Ручное ведение схем и метаданных в DWH** (интегрировано в T-SQL, сложное сопровождение)                                                                  |
| **BI и аналитика**                | - **Self-Service BI** (Power BI, Tableau, Looker)                                                                                                         | - **Embedded Analytics** (встраивание аналитики напрямую в доменные приложения)                                                                    | - **Semantic Layer** (LookML, Cube.js и др.) для единых бизнес-метрик                                                                                                      | - **Сложные OLAP-кубы на устаревшей платформе** (переводим в более гибкие инструменты)                                                                      |
| **Языки / Стек разработки**       | - **Java, Golang, Python** (основные для микросервисов, ИИ, финтех, ETL)                                                                                  | - **Kotlin** (пробуем в пилотных проектах, где Java-платформа подходит, но нужна более компактная модель)                                          | - **Rust** (может быть применён в высоконагруженных системах для безопасного низкоуровневого кода)                                                                          | - **PowerBuilder** (легаси-клиент для DWH, плановый отказ)                                                                                                  |
| **Оркестрация и контейнеризация** | - **Docker, Kubernetes** (основная платформа для деплоя микросервисов)                                                                                   | - **Service Mesh** (Istio / Linkerd) для продвинутой маршрутизации, безопасности и наблюдаемости в Kubernetes                                      | - **Serverless / FaaS** (AWS Lambda, OpenFaaS) — потенциальное использование для вспомогательных функций                                                                   | - **Загрузка на физические сервера вручную** (устаревшая практика, уходим в сторону DevOps)                                                                  |
| **Мониторинг и логирование**      | - **Prometheus + Grafana** (сбор метрик и визуализация)                                                                                                   | - **ELK/OpenSearch** (продвинутый сбор логов, анализ)                                                                                              | - **Jaeger / Zipkin** (распределённый трекинг запросов; рассматриваем для сложных цепочек)                                                                                 | - **Ручной сбор логов и неструктурированные файлы** (не масштабируется)                                                                                      |
